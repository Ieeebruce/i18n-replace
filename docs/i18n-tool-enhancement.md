# i18n-refactor 可视化工具增强功能说明

## 概述

本文档介绍了i18n-refactor可视化工具的最新增强功能，包括环境初始化作为第一步，以及增加了文件夹选择功能，使用户可以通过图形界面更方便地选择处理目录、字典目录和输出目录。

## 新增功能

### 1. 文件夹选择功能

现在工具界面中三个关键的目录配置项都增加了文件夹选择功能：

- **处理目录**：用于选择需要进行i18n重构的源代码目录
- **字典目录**：用于选择国际化词条字典文件所在目录
- **JSON输出目录**：用于选择重构结果输出目录

### 2. 用户界面改进

每个目录输入框旁边都有一个"浏览"按钮，用户可以：

- 点击"浏览"按钮打开目录选择模态框
- 在模态框中浏览可用的目录
- 选择相应目录后，路径会自动填充到输入框中
- 输入框设置为只读，确保路径的准确性

### 3. 技术实现

通过Node.js后端API实现安全的文件夹选择功能，避免了浏览器的安全限制：

- 前端发起目录列表请求到后端API
- 后端使用Node.js的fs模块安全地读取目录内容
- 返回目录列表供前端选择
- 包含安全检查以确保只能访问项目目录内的路径

## 使用方法

### 选择处理目录

1. 在工具界面的配置选项区域找到"处理目录"
2. 点击"浏览"按钮
3. 在弹出的目录选择模态框中浏览并选择要处理的源代码目录
4. 选中的路径会自动填入输入框

### 选择字典目录

1. 在工具界面的配置选项区域找到"字典目录"
2. 点击"浏览"按钮
3. 在弹出的目录选择模态框中浏览并选择国际化词条字典所在目录
4. 选中的路径会自动填入输入框

### 选择JSON输出目录

1. 在工具界面的配置选项区域找到"JSON输出目录"
2. 点击"浏览"按钮
3. 在弹出的目录选择模态框中浏览并选择重构结果的输出目录
4. 选中的路径会自动填入输入框

## 注意事项

- 目录选择通过Node.js后端API实现，确保了安全性
- 系统包含安全检查以确保只能访问项目目录内的路径
- 仍然可以通过手动编辑输入框来精确指定路径

## 工具模式

i18n-refactor工具支持以下5种模式：

1. **替换模式**：将旧的国际化访问方式替换为标准格式
2. **删除模式**：清理无用的属性声明
3. **字典处理**：处理字典文件
4. **注入国际化**：注入国际化模块
5. **环境初始化**：准备运行环境

每种模式都可以配合所选的目录配置进行操作。

## 配置选项

除了目录选择外，工具还提供以下配置选项：

- **语言列表**：指定需要处理的语言（默认为zh,en）
- **干运行模式**：预览变更而不实际修改文件（推荐在正式执行前勾选）

## 执行结果

执行完成后，工具会显示：

- 执行摘要（处理文件数、已更改文件数等）
- 详细结果（文件列表和具体变更）
- 输出日志（执行过程中的详细信息）

---

此增强功能使i18n-refactor工具更加易用，用户无需手动输入复杂路径即可快速配置工具参数。
