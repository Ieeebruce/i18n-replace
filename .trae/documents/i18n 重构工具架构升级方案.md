# i18n 重构工具全链路架构设计方案 (含字典迁移与服务注入)

本方案在原有分析与重构流程中，显式增加了**基础设施迁移 (Infrastructure Migration)** 阶段，确保词条数据先行就绪。

---

## 1. 系统核心架构：四阶段设计

| 阶段 | 模块名 | 核心职责 | 输出产物 |
| :--- | :--- | :--- | :--- |
| **S1** | **全项目分析器 (Analyzer)** | 基于 TS 类型系统，跨文件追踪变量流向，构建引用图。 | 引用关系图 |
| **S2** | **基础设施迁移 (Infra Migrator)** | **[新增]** 将 TS 字典转换为平铺 JSON，并注入标准 i18n 服务。 | `assets/i18n/*.json` + `I18nService` |
| **S3** | **规划引擎 (Planner)** | 生成代码替换计划，并校验新旧词条值的一致性。 | 重构清单 (Manifest) |
| **S4** | **执行引擎 (Transformer)** | 执行代码替换与格式化。 | 修改后的源码 |

---

## 2. 详细工作流 (Workflow)

### 步骤 1：扫描与分析 (Scan)
```bash
i18n-refactor scan
```
*   利用 `ts.createProgram` 全局分析项目，识别所有旧词条的使用点（基于污点分析）。
*   **产出**：旧词条使用点清单（但不生成最终 Plan，因为 Key 还没生成）。

### 步骤 2：字典迁移与服务注入 (Migrate & Inject)
```bash
i18n-refactor migrate
```
这是**新增的关键步骤**，负责“地基”建设：
1.  **字典转换 (TS -> Flat JSON)**：
    *   读取 `src/app/i18n/*.ts` (保留 export 结构)。
    *   将嵌套对象平铺为点分键值对 (Nested Object -> Dot Notation)。
    *   **示例**：`{ home: { title: 'Hi' } }` -> ` "home.title": "Hi" `。
    *   写入 `src/assets/i18n/*.json` (符合 Angular 标准方案)。
2.  **服务注入 (Service Injection)**：
    *   检查并生成 `I18nService` 文件（封装了 Angular 的 `TranslateService` 或 `I18n` 库）。
    *   **目标 API**：确保新服务支持用户指定的调用方式 `this.i18n.get({key: 'a.b.c'})`。

### 步骤 3：生成计划与校验 (Plan & Verify)
```bash
i18n-refactor plan
```
*   基于步骤 1 的使用点和步骤 2 生成的 JSON Key，生成替换代码。
*   **值一致性校验 (关键安全网)**：
    *   **比对源**：原始 TS 字典值 vs 新生成的 JSON 字典值。
    *   **逻辑**：确保 `Flatten('home.title')` 的值与 `Original.home.title` 完全一致。
    *   **产出**：带有校验状态的 `refactor-plan.json`。

### 步骤 4：审查 (Review - UI)
```bash
i18n-refactor ui
```
*   启动 Web UI。
*   **双重确认**：
    1.  代码 Diff：确认 `this.data.home.title` -> `this.i18n.get({key: 'home.title'})`。
    2.  值预览：确认 Key `home.title` 对应的文案未丢失或错乱。

### 步骤 5：应用 (Apply)
```bash
i18n-refactor apply
```
*   批量修改源码文件。

## 3. 核心算法细节

### 3.1 字典平铺算法
*   递归遍历 TS 导出的对象。
*   维护 Key 路径栈。
*   处理特殊字符转义（防止 Key 中包含点号导致解析错误）。

### 3.2 污点分析 (Taint Analysis)
（同前版）从 `getLocale()` 源头追踪到所有 Sink 点。

### 3.3 目标代码生成
根据用户要求，Transformer 将生成特定的调用格式：
*   **Input**: `this.common.submitBtn` (Path: `['common', 'submitBtn']`)
*   **Output**: `this.i18n.get({key: 'common.submitBtn'})`

---

## 4. 实施路线图

1.  **Infra 模块**：实现 TS 字典读取、平铺算法、JSON 写入。
2.  **Analyzer 模块**：实现基于 TypeChecker 的全项目引用追踪。
3.  **Planner 模块**：结合平铺后的 Key 生成替换计划，并实现值比对。
4.  **Transformer 模块**：适配新的 `get({key: ...})` 语法生成。
5.  **UI 模块**：适配新流程的展示。
